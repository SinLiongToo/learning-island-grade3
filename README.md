# 學習島（國小三年級～國中九年級）🏝️

國小三年級到國中九年級的課後複習網站。國小：自然、數學、國語、英語、社會、台語，加上資訊科技（電腦、網路、人工智慧）、國際世界觀、地球科學、健康、藝術、體育、理財和思考實驗；國中：國文、英語、數學、自然、社會等 13 科（含思考實驗島）。首頁可以切換年級。
每個單元都是「**先讀重點教學 → 再做 10 題練習**」，答得越好星星越多。
每一課都有「🤔 **想一想**」：先提問、自己想，再點開看一步一步的推理，最後示範「還可以再問」的好問題；練習題中標著「🧠 推理題」的題目，練習比較、找規律、找錯、判斷因果。
各年級國語島最後一課是「🙋 **提問小達人**」：三年級提問六寶（5W1H）、四年級開放式與封閉式問題、五年級追問與找證據、六年級事實與意見、可驗證的問題。

## 🧠 思考實驗島（三～九年級）

學校比較少專門教的「怎麼想、怎麼判斷」：科學方法、證據、偏誤、機率與估算。每個年級 3 課，共 21 課；每課都有「想一想」、8 題固定題（含 3 題推理題）和自動出題。

| 年級 | 單元 |
|---|---|
| 三年級 | 猜一猜再驗證（預測→驗證→觀察→想一想）、找規律找不同、事實還是想法 |
| 四年級 | 公平的實驗（一次只改一個條件）、估算大挑戰（隨身的尺）、科學迷思破解 |
| 五年級 | 證據有多強、一起發生不代表誰造成誰（背後的原因）、說話的陷阱（從眾、以偏概全等） |
| 六年級 | 會騙人的圖表（縱軸不從 0 開始，附示意圖）、樣本夠不夠（偏差與隨機抽樣）、科學家也會錯（日心說、鵝頸瓶、幽門螺旋桿菌） |
| 七年級 | 大腦的捷徑（確認偏誤、倖存者偏差、錨定、沉沒成本）、實驗變因與對照組、機率直覺陷阱（賭徒謬誤、大數法則） |
| 八年級 | 費米估算、風險怎麼比（相對與絕對風險）、系統思考（增強與平衡迴路、甘蔗蟾蜍） |
| 九年級 | 怎樣才算好研究（隨機、安慰劑、雙盲）、工程設計循環、怎麼判斷一個說法（可檢驗、舉證責任、奧坎剃刀） |

## 功能

- 練習每回合隨機抽題、選項順序打亂；可以一直重練
- 每課至少 8 題固定題，其中至少 2 題推理題；教學裡的「想一想」可以點開看推理步驟
- 答錯的題目自動收進 **錯題本**，重做答對才會移除
- **綜合挑戰**：目前年級的所有科目隨機混合 10 題
- **年級切換**：記住上次選的年級；打開某一課會自動切到那一課的年級
- 進度存在瀏覽器（localStorage），不需要登入
- 手機、平板、電腦都能用

## 使用

直接雙擊 `index.html` 就能開，不需要網路或伺服器。

```
js/data/*.js        三年級各科內容（js/data/g4、g5、g6/*.js 是四～六年級，科目有 grade 欄位）：
                    每個單元有 lesson（教學區塊）、quiz（固定題）、gen（自動出題，可省略）
js/data/ask.js      提問小達人（加在各年級國語島的最後一課）
js/data/finance.js  理財島（三～六年級）
js/data/jh/*.js     國中七～九年級（lib.js 是精簡格式的小工具；g7a/g8a/g9a 主科，g7b/g8b/g9b 其他科）
js/data/think.js    思考實驗島（三～九年級，用 jh/lib.js 的格式）
js/data/worldfig.js 國際島的示意地圖（七大洲五大洋、地標、自然奇景、首都、時差、東南亞、台灣位置），由 tools/mkmap.py 產生（python tools/mkmap.py js/data/worldfig.js）
js/data/more/*.js   補充內容：依單元 id 加上「想一想」、更多練習題和推理題（app.js 啟動時合併）
```

新增題目：在對應科目檔案的 `quiz` 陣列加一筆 `{ q, opts, ans, exp }`，`ans` 是正解在 `opts` 的位置（顯示時會自動打亂順序）。
也可以加在 `js/data/more/` 的檔案裡，寫成 `[題目, [正解, 錯1, 錯2, 錯3], 解說, 1]`（最後的 1 代表推理題）；「想一想」寫成 `[問題, [推理步驟…], 還可以問]`。補充的題目會接在原本題目後面，不影響錯題本的紀錄。
