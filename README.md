# 小學三年級・全能探索學習島 (Grade 3 All-Star Learning Island) 🏝️

專為台灣國小三年級（108 課綱）設計的 **3D 低多邊形（Low-Poly）互動探索學習 WebApp**，比照《自然挑戰島》架構打造，融合自然、數學、國語、英語、社會、台語六大領域，共 36 道精選題庫。

---

## ✨ 核心亮點

1. **3D 低多邊形六大主題群島（Three.js + OrbitControls）**
   - 360 度滑鼠/觸控旋轉、縮放與平移。
   - 六座島嶼形成完整環狀**木棧道橋樑（Boardwalks）**互相連接：
     - 🌿 **01 自然探險島**（6 題）
     - 🧮 **02 數學奇幻島**（6 題）
     - 📖 **03 國語智慧島**（6 題）
     - 🔤 **04 英語歡樂小鎮**（6 題）
     - 🏘️ **05 社會生活聚落**（6 題）
     - 🗣️ **06 歡喜講台語島**（6 題，本土語言臺灣台語）
   - 3D 浮空膠囊標籤（Pin）：橘紅/綠色圓形編號、科目名稱、即時星級進度（★ 0/6）。

2. **🚶‍♂️ 生動活潑的走動角色群**
   - **🍳 蛋蛋老師（DanDan Teacher）**：圓滾滾蛋形頭、荷包蛋小帽子、圓眼鏡與暖黃圍裙，頭頂懸浮 `🍳 蛋蛋老師巡島中`，逆向巡島關心學生！
   - **🎒 探險小學生**：黃色外套背著紅色小書包，雙腿與雙手前後規律擺動，步伐輕快彈跳。
   - **🐕 阿柴（小柴犬）**：翹著尾巴，邁著小短腿緊跟在小學生後方奔跑。
   - **⛵ 巡航帆船**：海面上兩艘小帆船隨波浪上下搖晃巡航。

3. **左右分割視窗連動（Split View）**
   - 左側 3D 舞台 ＋ 右側抽屜式目錄面板（THE ISLAND INDEX）。
   - 點擊左邊 3D 地標 Pin，右側側欄立即無縫切換至該領域試題；點擊返回目錄，鏡頭自動拉回全景。

4. **36 道 108 課綱精選素養題（含 6 題台語本土語言）**
   - 🗣️ **台語題庫亮點**：
     - 早起打招呼問候：**「𠢕早（gâu-tsá）」**
     - 童謠身體部位：**「跤（kha）」** 指的是腳
     - 在地美味水果：**「芎蕉（kin-tsio）」** 指的是香蕉
     - 可愛動物生動稱呼：**「水雞（tsuí-ke）」** 指的是青蛙
     - 家庭親屬親切稱呼：**「阿嬤（a-má）」** 指的是奶奶/外婆
     - 天氣與生活出門準備：**「落雨（lo̍h-hōo）」** 要帶雨傘

5. **國小專屬「🔊 聽題目朗讀」**
   - 每題均支援台灣標準語音朗讀，輔助三年級學童自主閱讀作答。

6. **錯題燈塔與數據保存**
   - 答錯題目自動進入「錯題燈塔島」，重新答對後點亮燈塔並消除標記。
   - 使用瀏覽器 `localStorage` 保存 36 顆星與 6 面金旗進度。

---

## 🚀 執行方式

直接對著 `index.html` 按兩下滑鼠左鍵開啟，或使用本機伺服器：
```bash
python -m http.server 8080
```
瀏覽器造訪 `http://localhost:8080`。
