# 學習島（三、四年級）🏝️

國小三、四年級六大領域的課後複習網站：自然、數學、國語、英語、社會、台語。首頁可以切換「三年級／四年級」。
每個單元都是「**先讀重點教學 → 再做 10 題練習**」，答得越好星星越多。

## 功能

- 練習每回合隨機抽題、選項順序打亂；可以一直重練
- 答錯的題目自動收進 **錯題本**，重做答對才會移除
- **綜合挑戰**：目前年級的六科隨機混合 10 題
- **年級切換**：記住上次選的年級；打開某一課會自動切到那一課的年級
- 進度存在瀏覽器（localStorage），不需要登入
- 手機、平板、電腦都能用

## 使用

直接雙擊 `index.html` 就能開，不需要網路或伺服器。

## 檔案結構

```
index.html          頁面外框
css/style.css       樣式
js/app.js           程式（路由、練習、錯題本、語音、互動小工具）
js/data/*.js        三年級各科內容（js/data/g4/*.js 是四年級，科目有 grade: 4）：
                    每個單元有 lesson（教學區塊）、quiz（固定題）、gen（自動出題，可省略）
```

新增題目：在對應科目檔案的 `quiz` 陣列加一筆 `{ q, opts, ans, exp }`，`ans` 是正解在 `opts` 的位置（顯示時會自動打亂順序）。

## 備註

- 內容依 108 課綱三、四年級學習重點編寫；各版本教科書單元順序不同。
- 瀏覽器沒有台語語音，所以台語科不提供朗讀，避免用華語唸台語字。真人發音請查[教育部臺灣台語常用詞辭典](https://sutian.moe.edu.tw/)。
- 英文 KK 音標由 [CMU Pronouncing Dictionary](https://github.com/cmusphinx/cmudict)（美式發音）自動轉換，少數字經人工校正。
