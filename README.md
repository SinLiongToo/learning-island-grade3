# 三年級學習島 🏝️

國小三年級六大領域的課後複習網站：自然、數學、國語、英語、社會、台語。
每個單元都是「**先讀重點教學 → 再做 10 題練習**」，答得越好星星越多。

## 內容

| 科目 | 單元 | 特色 |
|---|---|---|
| 🧮 數學 | 8 | 一萬以內的數、加減、乘法、除法與餘數、分數、小數、時間、長度容量重量。**每課都會自動出題**，練不完 |
| 🌿 自然 | 7 | 植物的身體、葉、根莖與蔬菜部位、磁鐵、空氣與風、水的移動、動物 |
| 📖 國語 | 8 | 部首查字典、量詞、形近字、修辭、標點、連接詞、成語、閱讀理解短文 |
| 🔤 英語 | 8 | 短母音、數字、顏色形狀、文具、動物、家人、身體、日常對話；單字卡可按 🔊 聽發音 |
| 🏘️ 社會 | 6 | 親屬稱謂、學校生活與班會、方位與地圖、公共設施與安全、節慶、家鄉特色 |
| 🗣️ 台語 | 7 | 相借問、數字與時間、厝內人、身軀、果子、動物、天氣佮色水（漢字＋臺羅） |

互動小工具：位值板（數學）、分數披薩（數學）、撥時鐘算經過時間（數學）、面向方位（社會）。

## 功能

- 練習每回合隨機抽題、選項順序打亂；可以一直重練
- 答錯的題目自動收進 **錯題本**，重做答對才會移除
- **綜合挑戰**：六科隨機混合 10 題
- 進度存在瀏覽器（localStorage），不需要登入
- 手機、平板、電腦都能用

## 使用

直接雙擊 `index.html` 就能開，不需要網路或伺服器。

## 檔案結構

```
index.html          頁面外框
css/style.css       樣式
js/app.js           程式（路由、練習、錯題本、語音、互動小工具）
js/data/*.js        各科內容：每個單元有 lesson（教學區塊）、quiz（固定題）、gen（自動出題，可省略）
```

新增題目：在對應科目檔案的 `quiz` 陣列加一筆 `{ q, opts, ans, exp }`，`ans` 是正解在 `opts` 的位置（顯示時會自動打亂順序）。

## 備註

- 內容依 108 課綱三年級學習重點編寫；各版本教科書單元順序不同。
- 瀏覽器沒有台語語音，所以台語科不提供朗讀，避免用華語唸台語字。真人發音請查[教育部臺灣台語常用詞辭典](https://sutian.moe.edu.tw/)。
